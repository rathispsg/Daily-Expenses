DAILY EXPENSE TRACKER — INSTALLABLE WEB APP

This package is a Progressive Web App (PWA). It can be installed on Android from Chrome and then appears like an app icon. It works offline after the first successful load.

IMPORTANT:
- A PWA must be hosted on an HTTPS website (or localhost) before Chrome can install it. Opening index.html directly from Downloads will not enable installation/offline caching.
- This package is not an APK.
- Expense data is stored in the browser's local storage on this device. Do not clear browser site data; use Backup all data regularly.
- Monthly export currently creates a CSV file that opens in Excel.
- Automatic monthly email is not configured; that requires a secure backend/email scheduler.

HOSTING OPTIONS:
Upload the contents of this folder to an HTTPS static host such as GitHub Pages. Then open the published HTTPS URL in Chrome on Android, choose the browser menu, and select Install app or Add to Home screen.
